# 📊 WorkInsight – AI-Powered HR Decision Intelligence Platform

## 📌 Project Overview

WorkInsight is an AI-powered HR Analytics platform developed using Python, Streamlit, and Machine Learning. It helps HR teams analyze workforce data, visualize employee trends, and predict employee attrition.

---

## 🚀 Features

- 📊 Interactive Dashboard
- 📈 HR Analytics
- 👥 Employee Statistics
- 💰 Salary Analysis
- 📉 Attrition Analysis
- 🤖 Employee Attrition Prediction
- 🔍 Department Filter
- 📋 Top 10 Highest Paid Employees
- 💡 HR Recommendations

---

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib
- Streamlit

## ▶️ Run the Project

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
